# Правила работы с этим проектом (для Claude и других ИИ)

## Как общаться с владельцем проекта

- Язык общения — русский.
- Каждое действие, которое нужно сделать человеку, давать **пошаговой инструкцией от и до**:
  - где именно это делать (какая программа, какое окно, какая папка);
  - на что нажать и что ввести — точный текст команды в блоке кода, чтобы его можно было скопировать;
  - когда это делать (в каком порядке, чего дождаться перед следующим шагом);
  - **ожидаемый результат** каждого шага: что должно появиться на экране;
  - что делать, если результат другой (самые частые ошибки и как их исправить).
- Не пропускать «очевидные» шаги. Шаги нумеровать, один шаг = одно действие.
- Владелец работает на Windows (PowerShell), проект запускается через Docker Desktop.

## Проект

- EventOps: B2B SaaS PWA для мероприятий. Backend: Django + DRF + SimpleJWT (Supabase Postgres). Frontend: React + Vite + Tailwind.
- Дизайн: артефакт «EventOps» (канвас с макетами); фронт повторяет его классы Tailwind.
- Подробности запуска и устройства — в README.md.
